# Contribuir

Abre un issue describiendo el comportamiento esperado, equipo/modelo y pasos para reproducir. No publiques datos personales ni respaldos reales.

Usa Node 24+, `npm ci`, `npm test`, `npm run build` y `npm run test:e2e`. Mantén TypeScript estricto y las pruebas de compatibilidad. Los cambios visuales requieren revisión en móvil/escritorio, claro/oscuro, teclado y movimiento reducido.

Para una ficha nueva: agrega ID estable, fuente primaria, nivel, posición, accesorios, músculos principales/secundarios, instrucciones originales, precauciones y estado de revisión. Videos solo con licencia/permiso verificable; nunca copies un catálogo propietario. No conviertas colores de distintas marcas en equivalencias físicas.

No agregues APIs de pago, telemetría ni dependencias de cuentas para el primer uso. Los cambios de esquema necesitan migración Dexie y pruebas de respaldo. Una configuración debe seguir ligada al equipo y su revisión; una omisión jamás se convierte en una serie completada.
